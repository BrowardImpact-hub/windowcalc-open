================================================================================
                         API REQUIREMENTS
================================================================================

The app expects these endpoints on the Flask backend:

POST /api/mobile/sessions
  Request: { email, password, device_id, device_name, platform }
  Response: { token, expires_at, user }

GET /api/mobile/bundle/{repId}
  Response: MobileBundle (quotes, products, glass_options, frame_colors, governance)

GET /api/quotes/{id}
  Response: Quote

GET /api/quotes/{id}/price-bounds
  Response: PriceBounds[]

POST /api/quotes/{id}/bulk-adjust
  Request: { adjustment_pct }
  Response: { total_price, openings[] }

POST /api/quotes/{id}/generate-narrative
  Response: { narrative }

POST /api/openings
  Request: { quote_id, opening_type, total_width, total_height, ... }
  Response: Opening

PATCH /api/openings/{id}
  Request: { sell_price, ... }
  Response: Opening

POST /api/mobile/sync/events
  Request: { device_id, events[] }
  Response: { processed, failed }

All endpoints require: Authorization: Bearer <token>

                           SUPPORT & NOTES

Troubleshooting:

Q: Build fails with "module not found"
A: Run 'npm install' and 'expo start -c' to clear cache

Q: Blank screen on launch
A: Check app/_layout.tsx - auth/sync initialization may be hanging
   Verify .env is correct with backend URL

Q: Haptics not working
A: On iOS Simulator: unavailable, works on real device
   On Android: device-specific support

Q: Sync events not flushing
A: Check network connectivity indicator
   Verify backend URL in .env
   Check browser DevTools Network tab for CORS/auth issues

Development Tips:

1. Use expo-router for all navigation (no react-navigation setup needed)
2. Zustand stores subscribe to updates automatically (no hooks needed)
3. Theme system automatically applies to all screens
4. AsyncStorage loads theme before first render (no flicker)
5. Sync queue works offline - never show users that data is lost

Performance Tips:

1. Bundle cache is the source of truth - refresh in background
2. Don't refetch quotes on every navigation - use cached data
3. Price slider updates are local first, sync to server on release
4. Sync batching at 50 events per request - adjust in constants/api.ts
