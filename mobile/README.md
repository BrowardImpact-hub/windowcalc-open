# WindowCalc Mobile

Expo (SDK 51) / React Native 0.74 field app for WindowCalc - quotes, openings
and pricing, offline-first with background sync. Part of the public-domain
WindowCalc release; see the [top-level README](../README.md).

```bash
npm ci
cp .env.example .env
npm start
```
